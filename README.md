# VYOMVERSE

A light and fast website about the universe. It covers the Big Bang, the solar system, stars and galaxies, the history of space exploration, and India's journey in space (ISRO, Chandrayaan, Mangalyaan and more).

- 8 pages, fully responsive
- Planets spin using CSS animations
- No JavaScript, no external images, works offline

## How to run
Keep all files in one folder and open `index.html` in a browser.

## Pages
index, universe, solar-system, stars, exploration, india, about, contact
